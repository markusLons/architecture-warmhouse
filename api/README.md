# Документация API

Файл [openapi.yaml](openapi.yaml) содержит пять REST-эндпоинтов будущей системы.

Для просмотра откройте [Swagger Editor](https://editor.swagger.io/) и вставьте содержимое файла в редактор.

| Сервис | Метод | Путь |
| --- | --- | --- |
| Реестр устройств | GET | `/devices?house_id={id}` |
| Сервис сенсоров | GET | `/sensors/{device_id}/temperature` |
| Сервис исполнительных устройств | POST | `/devices/{device_id}/commands` |
| Сервис исполнительных устройств | GET | `/devices/{device_id}/state` |
| Сервис камер | GET | `/cameras/{device_id}/stream` |

Пути указаны относительно API соответствующих сервисов. Это контракт To-Be, а не маршруты учебного монолита из задания 5.

Температура и состояние возвращаются вместе со временем измерения или подтверждения. Ответ 202 на команду означает, что она принята, а не выполнена. Ссылка RTSP предназначена для RTSP-плеера; браузер не воспроизводит этот поток напрямую.
